## Dependencies

- [npm](https://docs.npmjs.com)
- [wallet-api](https://github.com/AndreaGiorgino/wallet-api)

## Run

```bash
git clone git@github.com:AndreaGiorgino/wallet
cd wallet

npm install
npm run dev
```
